## 🧮 Задание 1. Калькулятор (`Calculator.py`)

Графический калькулятор с поддержкой базовых и инженерных вычислений, а также полноценным управлением с клавиатуры.

### Возможности:
* **Базовые операции:** сложение (`+`), вычитание (`-`), умножение (`*`), деление (`/`).
* **Инженерные функции:**
  * Возведение в квадрат (`x²`)
  * Извлечение квадратного корня (`√`)
  * Возведение в произвольную степень (`x^y`)
* **Скобки:** поддержка вложенных скобок `( )`.
* **Проценты (`%`):** умный расчет процентов (например, `200+10%` автоматически посчитает 10% от 200 и прибавит, выйдет `220`).
* **Ввод с клавиатуры:** можно вводить цифры и знаки прямо с клавиатуры, не нажимая на кнопки мышью.
* **Валидация ввода:** программа запрещает вводить буквы и лишние символы.
* **Обработка ошибок:** деление на ноль, корень из отрицательного числа и ошибки синтаксиса выводятся прямо в поле ввода (без всплывающих окон, блокирующих работу).

### Управление:
* **Мышь:** нажатие на экранные кнопки.
* **Клавиатура:**
  * Цифры и знаки `+`, `-`, `*`, `/`, `(`, `)` вводятся как обычно.
  * `Enter` — посчитать результат (аналог `=`).
  * `Backspace` — удалить один символ.
  * `Delete` или `Escape` — полностью очистить поле (аналог `C`).
  * **Корень и квадрат:** при нажатии на `√` в поле появится `sqrt(`, вам останется ввести число и нажать `=` (программа сама закроет скобку); при нажатии на `x²` добавится `^2`.
  * **Степень:** кнопка `x^y` добавляет символ `^` (например, `2^3` при нажатии `=` даст `8`).

### Запуск:
```bash
python3 Calculator.py
```

## 📂 Задание 2. Формы учёта-отчёта (`main.py`)

Приложение для учета пациентов, реализованное по архитектуре **MVC (Model-View-Controller)**. Состоит из 4 файлов: `main.py`, `Model.py`, `View.py`, `Controller.py`.

### Возможности:
* Добавление пациентов (ФИО раздельно на фамилию, имя и отчество).
* Автоматический расчет индекса массы тела (ИМТ).
* Редактирование и удаление записей.
* Автоматическое сохранение данных в файл `patients.json` и загрузка при старте.
* Генерация тестовых данных (50 случайных пациентов) одной кнопкой.
* **Статистика:** построение 4 графиков (распределение по полу, по возрасту, ИМТ с учетом пола и зависимость ИМТ от возраста).

### Запуск:
> *Примечание: файлы `Model.py`, `View.py` и `Controller.py` должны находиться в одной папке с `main.py`.*

```bash
python3 main.py
```

## 🧬 Задание 3. Урезанный FastQC (`fastq_gui.py`)

Графическая оболочка для модуля анализа FASTQ-файлов из группового проекта. Состоит из 2 файлов: `fastq_gui.py` (интерфейс) и `fastq_module.py` (логика парсинга и подсчета).

### Возможности:
* Выбор файлов через стандартный диалог с фильтром по форматам (`.fastq`, `.fq`, а также сжатые архивы `.gz`).
* Быстрый потоковый анализ файла «на лету» (без загрузки всего файла в оперативную память).
* Построение трех графиков статистики в одном окне:
  * Среднее качество по позициям (*Per base sequence quality*).
  * Состав нуклеотидов по позициям (*Per base sequence content*).
  * Распределение длин ридов (*Sequence length distribution*).

### Запуск:
```bash
python3 fastq_gui.py
```
В открывшемся окне нажмите кнопку **«Выбрать FASTQ файл»** и укажите путь к вашему файлу формата `.fastq`.
